# Student Management System

## 1. Project Description

The Student Management System is a Python-based application that helps users manage student records efficiently. It allows users to add, view, search, update, and delete student information. The application stores student records in a JSON file so that the information remains available after restarting the program.

## 2. Project Objectives

* To develop a practical Python application.
* To manage student records efficiently.
* To implement file handling and exception handling.
* To demonstrate Object-Oriented Programming concepts.
* To learn Git and GitHub repository management.

## 3. Features

* Add new student records.
* View all registered students.
* Search for students using their IDs.
* Update student information.
* Delete student records with confirmation.
* Calculate student grades automatically.
* Save and load records using a JSON file.
* Validate user input and handle errors.

## 7. Installation and Setup

1. Install Python on your computer.
2. Install Visual Studio Code.
3. Download or clone the project repository.
4. Open the project folder in Visual Studio Code.
5. Open the integrated terminal.

## 8. How to Run the Project

Run the following command in the terminal:

```bash
python main.py
```

If the `python` command is unavailable on Windows, try:

```bash
py main.py
```

Follow the menu displayed in the terminal to manage student records.

## 9. Data Storage

Student information is stored in `students.json`. The application creates this file when records are saved. Existing records are loaded when the program starts.
